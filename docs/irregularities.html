AUDIT TRAIL / ACTION ITEMS

Known limitations

Failures and uncertainty are part of the result. No human inspector is used to override the gates.

IR-01 / HARD STOP

The lattice makes the literal test unusually restrictive

The verified registry lattice covers 5,160,724 of 5,167,373 footprint pixels within 3 pixels. Only 6,649 pixels are outside that radius. For any 37,654-dot candidate, at least 82.34% must overlap by the pigeonhole principle; this candidate actually overlaps 99.968%.

This does not prove geological copying: the lattice is a space-filling calibration pattern. It nevertheless triggers the user's unqualified “any registry raster” stop. A better scientific comparator policy requires an explicit protocol change; this project must not create an exception on its own.

IR-02 / EVIDENCE

Historical approval was invalid

Prior code excluded the lattice, reported detector-only passing results, and labeled owner-supplied values as organizer-confirmed. The old approval flags have been superseded. The re-audit checks nine historical rasters plus the lattice; it does not claim a complete registry replay or recomputed pre-placement surface.

IR-03 / ACCESS

Official input and quota access

The official data and submission pages redirect to login. A public GitHub mirror restored the feature, template and label files, with hashes checked; identical hashes do not prove organizer origin or permission. The prepared feature-stack hash matches the historical cache. Official files, independent source verification and account quota remain unavailable here.

IR-04 / INFERENCE

A holdout is not the leaderboard

Mapped-fault hide-and-recover is an imperfect proxy for newly expert-mapped faults. Scores from different evaluators or label populations are not directly comparable. Neither a historical point estimate nor a fit to a few reported values establishes performance on hidden test data.

The selector is intentionally fail-closed until a complete independent replay and a legitimate account quota adapter exist. The static leaderboard snapshot is dated 2026-10-27; the organizer's live page remains the source of truth.
