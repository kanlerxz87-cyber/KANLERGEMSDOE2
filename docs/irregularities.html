Known irregularities and current handling

1 · Historical score provenance

Previous records called site scores ORGANIZER-CONFIRMED while citing owner-controlled receipt ledgers that were not present in this workspace. This review did not retrieve a DrivenData receipt. All nine values are now labeled USER/OWNER-REPORTED · UNVERIFIED.

Official leaderboard review link: DrivenData GEMS public leaderboard. No current ranking claim is made.

2 · GEMSDOE32 0.2778 inversion withdrawn

A prior three-point regression was treated as proof of hidden-set size, weighted true-positive count, and zero true positives among removed catalogue-collar pixels. The regression is non-identifying: weighted TP, FP, FN, kernel overlap, and the hidden set all vary with pixel placement. The score/count fit does not isolate them. The inference and its implied projections were deleted.

3 · Legacy holdout self-censoring

Some older per-site Hide-and-Recover results used static full-catalogue distance collars. A full-catalogue collar can remove predictions near a withheld segment, self-censoring the evaluation. Those old per-site holdout values are not displayed as calibrated live-score proxies. The frozen current-candidate record is retained with its evaluator/version and is explicitly not rerun in this audit.

4 · Evaluator entrypoint mismatch fixed

scripts/evaluate_holdout.py formerly contained an MTR1/multi-experiment runner despite its documented evaluator role and could fall through to an old experiment. It now delegates normal candidate evaluation to the canonical spatially blocked holdout evaluator. The legacy --verify-kg2 path is read-only artifact verification; it cannot run MTR1, launch another experiment, select a slot, or authorize an upload.

5 · Missing independent pre-placement surface

The prior run card records a maximum absolute surface Spearman value of 0.179514 against 192 registry rasters. The actual pre-placement surface array was not retained, so this review could not reproduce that check. The current final-dot audit against nine pinned focus-site TIFs is independently recomputed; it is not a substitute for the full registry surface check.

6 · Mirror provenance

Competition and external data restored from owner-controlled GitHub mirrors matched their pinned hashes. This proves consistency with the mirror manifest, not official-host authenticity, licensing beyond the cited record, or organizer score provenance. The competition data page is login-walled and was not accessed.

7 · No live selector or upload

The candidate is format-safe, downloadable, and recorded as selector-eligible. It is not authorized to submit: no live slot was selected and no upload was performed. The static status feed does not poll DrivenData and should not be read as live standings.

8 · Parallel KG2 lane archived separately

KG2-MGHV has a separate archived run card and a different holdout evaluator. Its DTI cannot be compared numerically with HTCADS results. It is not selected as the current candidate and cannot overwrite the active run card through its verifier.
