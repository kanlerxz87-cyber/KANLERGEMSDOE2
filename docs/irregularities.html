No organizer receipt ties the score to the SHA-pinned file. The geometry is reproducible; which hidden labels were detected, and whether the 6,436-pixel pruning caused a gain, cannot be established.

CORRECTED · implementation semantics

Feature index 28 was misnamed

HTCADS code computed cosine-squared axial strike alignment to a fixed 62° axis, not Anderson slip tendency. The shared feature name is corrected to strike_alignment_fixed_62deg; values are unchanged. Old run cards and canaries preserve the old historical label and are not evidence of a stress calculation.

SCIENTIFIC LIMITATION

“Upgradient” uses topography as a proxy

The plume transport direction is derived from smoothed detrended terrain elevation. No measured groundwater hydraulic head is consumed by this code, so it cannot be described as an observed hydraulic gradient or groundwater-flow vector.
