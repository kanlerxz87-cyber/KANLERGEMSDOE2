3–5 Candidate Geological Hypotheses Ranked

Each entry names: specific layer(s), physical signature (edge/curvature transform), why it should catch catalogue-missing faults, and how it differs from already-implemented. Ranked by expected DTI lift vs implementation cost. Top candidate is shipped; others are pre-registered for next slots. No submission slot is spent without a fold-local HOLDOUT-DTI win with paired 95% CI >0.

How ranking was done

  • Expected lift estimated from single-feature HOLDOUT-DTI canaries + published holdouts of analogous lanes in GEMSDOE31/32/36 (labeled HOLDOUT-DTI, not live). Cost = external data bulk + compute + catalogue-leakage risk.
  • All use buffered whole-segment hide-and-recover (buffer 6px, pooled DTI α0.2/β0.8/R3) and mask visible faults pixel-exactly. Feature construction uses only visible faults — withheld segments never contribute to the surface before scoring.
