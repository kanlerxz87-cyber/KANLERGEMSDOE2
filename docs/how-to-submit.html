“Predicted values must be in range [0, 1]” — root cause & fix

Causes: NaN/Inf cells, the float32 nodata sentinel (−3.4e38, present even inside the footprint in training_features.tif) leaking into outputs, or unbounded model values. Fix shipped here (scripts/submission_writer.py): binary {0,1} float32, 0 outside footprint and on catalogue, nodata=None, then machine-validation of all 12,279,160 cells against the sample grid before release (receipt JSON beside the TIF). Never blindly clip to hide a bug — this writer only writes an already-binary mask.
