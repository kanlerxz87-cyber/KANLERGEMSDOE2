How to make a submission

Automated evidence first; a separate selector must approve any real slot.

Current status: DO NOT SUBMIT

There is no new approved TIFF. Do not upload a historical reference or the quarantined E1 file. No competition slot was used in this review.

1. Generate and automatically verify

  1. Establish one exclusive method lane; use verified inputs and the pinned shared evaluator and writer. Freeze the complete parallel registry and a reproducible, fold-local current-best baseline.
  2. Run a holdout canary for every actual feature; flag AUC above 0.90. Hide entire fault components with a buffer, compute catalogue-based features from visible faults only, mask those pixels exactly, and report pooled HOLDOUT-DTI, evaluator version, withheld-positive count and 95% CI.
  3. Check the candidate surface before placing dots, then the final dots against the complete registry. Stop on a rank correlation over 0.90 or candidate-directional overlap over 70% within 3 pixels. No calibration exemption is authorized here.
  4. Use the shared writer to produce a float32 single-band GeoTIFF with finite predictions in [0,1] inside the footprint and exact CRS, dimensions and transform. The public format says null/NaN outside bounds; our conservative check uses the template footprint. Authenticate the sample and resolve that interpretation before release.
  5. Run the separate selector after scientific and format gates pass. The official rules PDF stated three submissions per week at this audit; the current account allowance and any changes must be checked on the authenticated page. A format PASS does not authorize a slot.

3. Only after selector approval
