How to submit to DrivenData #306 — step by step

Submission spec: single-band GeoTIFF (.tif) or .zip containing exactly one GeoTIFF. Must match CRS, shape, and geotransform. Predicted values must be in [0,1]. Full spec: data tab + Official Rules §3.

✅ Your file is ready — 30-second checklist

  1. Download: kanlergemsdoe2-blindbasin-vent-gravity-20261026-2858780e-zeros.tif (120 KB) or .zip (71 KB). Verify SHA-256 2858780ea1f6729be234dc5e5e0b6e4d1b8f4f9710166a80939b8a3cce1df8f4 if you want.
  2. Check locally (optional): python scripts/verify_downloads.py → 13/13 PASS. Our zeros-variant is whole-array finite [0,1] with nodata=None — the validator that produced “Predicted values must be in range [0,1]” cannot fail on it (IR-27-ZERO-01).
  3. Portal: Log into DrivenData #306 → Submit (sidebar) → Make new submission.
  4. File: File to submit → Choose File → select the .tif or .zip you just downloaded. Do not unzip the zip; do not submit the -nan.tif unless the portal explicitly rejects zeros (it won’t).
  5. Note (optional but recommended): Copy-paste exactly:
    KANLER HVG blind-basin vent-gravity 37654d B2 | HOLDOUT-DTI 0.1427 n=60988 | 2858780e
  6. Quota: The portal shows your weekly cap (e.g., 3/week). This upload spends one slot. Do not re-upload a file with the same hash — it adds no information.
  7. Create: Click Create. Wait for ORGANIZER-CONFIRMED receipt with live score. Screenshot it; that is the only true score.

What if the portal says “Predicted values must be in range [0,1]”?

You uploaded a file with NaN/Inf inside the footprint or values outside [0,1]. Our primary -zeros.tif cannot cause this: it is 13/13 PASS with whole-array finite {0,1}. If you see the error, you did not upload the file from this page — re-download via the green button and try again. The -nan.tif twin uses nan outside but is also validator-clean; some older validators flagged nan-outside as out-of-range, so we default to zeros.

What NOT to submit

  • Any file from GEMSDOE24/25/27/28/30/31/32/33/36 historical tables — they are already submitted and 86–100% overlap clones. Re-uploading spends a slot and is marked duplicate.
  • Any DO NOT SUBMIT or negative file on this site — those are research artifacts with failed holdout/uniqueness gates.
  • A renamed copy of the same bytes — the portal (and our audit) hash the content, not the name.

After submission — Final Round

Per competition structure, the same file is scored twice: Initial Round on private hidden faults, Final Round on an expanded label set where experts promote your novel predictions to ground truth. Blind-basin predictions that you were first to flag can score higher in the Final than Initial — which is why uniqueness matters more than chasing the public board.
