How to submit—only after approval

Current status: BLOCKED. There is no approved file.

1. Generate and validate

Reuse the selected template’s canonical submission_writer.py. Validate the reopened final bytes against the organizer sample: single-band float32 GeoTIFF, exact CRS/shape/geotransform, finite predictions in the sample-template footprint and values in [0,1], with null/nodata outside the footprint. Run the repository checker with python scripts/validate_submission.py --template data/sample_submission.tif --candidate candidate.tif --json candidate-audit.json after installing requirements-validation.txt. It validates format only; it does not approve a submission. Never blindly clip an invalid model output to hide a bug.

2. Verify scientific eligibility

Require feature-alone canaries, buffered whole-segment fold-local evaluation, positive paired improvement confidence interval and complete surface/dot uniqueness checks. Record SHA256, unique submission name and a note no longer than 140 characters.

3. Separate selector

Promotion means eligible for selection, not authorized upload. Check the authenticated weekly cap and current rules before spending a slot. This project has made no submissions.

4. Upload the approved artifact

At the official competition, use New submission. Upload the approved .tif or a .zip containing just that GeoTIFF, and copy its manifest note. Preserve the organizer receipt tied to the exact final raster hash. Only receipt results may be labeled ORGANIZER-CONFIRMED.
