How to submit (when cleared).

No file is cleared. The steps below apply only after the automated gates pass and the owner records a cleared decision. Current run card: verdict negative, ok_to_submit false.

  1. Confirm the file's SHA-256 and single-band grid against the card. Do not use a renamed or archived file.
  2. Open DrivenData → Submit → Make new submission, upload the GeoTIFF (or a ZIP containing that one TIFF) and enter the ≤140-character note.
  3. Record the organizer submission-page receipt (timestamp and SHA-256). Only that receipt makes a score ORGANIZER-CONFIRMED.
