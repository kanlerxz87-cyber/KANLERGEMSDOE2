HOW TO SUBMIT — WHEN A FILE IS APPROVED

Five steps, no guesswork

  1. Open the current run card.Proceed only if a fresh, independent selector explicitly authorizes the exact SHA-256. It does not currently do so.
  2. Download its named .tif.Confirm single band, float32, the competition CRS, shape and geotransform, and values in [0, 1].
  3. Check the official account.Sign in, verify remaining weekly allowance and rules on DrivenData submissions ↗.
  4. Choose New submission.Select the file or a ZIP containing exactly one TIFF; use the run card's unique name and note of at most 140 characters.
  5. Keep the receipt.Record the organizer's result and the exact file hash. Do not call a projection or holdout an organizer score.
FORMAT & QUOTA CAVEAT

What the checks can—and cannot—prove

The current file has no NaNs anywhere and passes the local whole-array [0, 1] test. The organizer's published format says data outside the bounds are null/NaN. The relation between those bounds and the irregular mirrored footprint is not established here; neither encoding is guaranteed accepted.

Current-account quota and submission receipts require login; this project has no account access and no independent replay certificate. Its selector therefore remains fail-closed. The system does not upload.
