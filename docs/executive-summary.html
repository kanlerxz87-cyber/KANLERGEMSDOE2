How submission will work

These are instructions, not current authorization. No weekly slot was used in this review.

  1. Run the gates, then the independent selector. Require fold-visible-only catalogue features, all feature canaries, comparable holdout improvement with CI, literal full-registry checks before/after placement and verified current quota.
  2. Download the exact approved TIFF. Confirm its SHA-256 and single-band grid against the authenticated sample. Do not use a renamed historical or negative file.
  3. Open DrivenData → Submit → Make new submission. Select the approved GeoTIFF (or ZIP containing that one TIFF) and enter its unique name and short note, at most 140 characters.
  4. Record the organizer receipt. Only an actual submission-page receipt can establish the file’s live score; add its timestamp and exact SHA-256.

Format versus acceptance

The official format specifies a single float32 band in [0,1], EPSG:32611 and the supplied grid, with null/NaN outside bounds. The owner mirror’s irregular exterior is NaN; the prior file uses zeros.

The earlier Predicted values must be in range [0, 1] error has no retained rejected-file bytes or organizer diagnosis. A local whole-array check rules out that particular value-range condition in the reviewed file, but does not prove portal acceptance.
