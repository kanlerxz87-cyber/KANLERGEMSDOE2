How to make a submission

Submission instructions (DrivenData)

  1. Clear every gate first. Format ([0,1], no NaN inside footprint, CRS/shape/transform match), holdout DTI with 95% CI, leakage canary ≤0.90 per feature, literal registry uniqueness (|ρ| ≤ 0.90 and ≤70% of dots within 3 px of any one registry raster), and current weekly quota.
  2. Download the exact approved GeoTIFF (or a ZIP containing that single TIFF) and verify its SHA-256. No file on this page is approved to submit today.
  3. DrivenData → Submit → Make new submission. Upload the single-band GeoTIFF. Enter a unique name and a short note (≤140 characters), e.g. clustering with k=25.
  4. Preserve the submission receipt (file hash, timestamp, organizer-returned score). Choose one final entry for both rounds before the deadline.

Format requirements

Single-band float32 GeoTIFF, values in [0,1], CRS EPSG:32611, shape 3730×3292, transform (100, 0, 243350, 0, −100, 4508550), null/NaN outside the scored footprint. The "Predicted values must be in range [0, 1]" error means a value lies outside [0,1] somewhere in the array (including exterior NaN under a strict whole-array read).
