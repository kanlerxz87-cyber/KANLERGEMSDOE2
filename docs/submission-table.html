Future instructions · not authorization

How to make a submission, once cleared.

  1. Verify all gates and the independent selector. Require fold-visible-only features, per-feature canaries, a comparable holdout win with CI, literal complete-registry checks on surface and dots, and current account quota.
  2. Download the exact approved TIFF. Verify its SHA-256, one float32 band, CRS, shape, transform and in-footprint [0,1] values against the authenticated sample. No file is approved today.
  3. Open DrivenData → Submit → Make new submission. Choose the approved GeoTIFF or ZIP containing that single TIFF. Enter the unique name and short note, at most 140 characters, and check current site limits.
  4. Preserve the actual submission receipt. Record the file hash, timestamp and score only if returned by the organizer. Choose one final entry for both rounds before the deadline.

Format versus acceptance

The official format specifies a single float32 layer in [0,1], EPSG:32611, matching bounds and 100 m grid, with null/NaN outside bounds. The owner-mirrored template has an irregular NaN exterior; this candidate uses zeros there.

The rejected file bytes and organizer diagnosis for Predicted values must be in range [0, 1] were not retained. A local whole-array check does not establish portal acceptance of either exterior convention.
