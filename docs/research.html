Ranked new hypotheses

Rank 1 · local mirrored data

Geothermometer discordance / disequilibrium

H-K1 uses maximum quartz/chalcedony/Na-K-Ca values. New transform: estimate robust inter-geothermometer spread and pairwise residuals (only compare measured temperatures when source definitions support it), then test a spatially sparse, uncertainty-weighted field gated by visible structural evidence. Potential is moderate but low-confidence because thermometer columns are sparse; implementation cost is low-to-moderate. Mimics include shallow mixing, boiling/cooling, sample differences, and host-lithology effects.

DOE GDR #1391 · official source record; current bytes in the workspace are owner-mirror copies. Never use dist_known_fault_px.

Rank 2 · new official imagery

Landsat SWIR hydrothermal alteration

Construct seasonally robust clay/hydroxyl and carbonate/silica-sensitive surface-reflectance composites, mask clouds/vegetation/playa moisture/mines, residualize by lithology and illumination, then aggregate 30 m anomalies to the 100 m grid. Potential is moderate; cost medium-to-high. Mimics include lithologic contacts, evaporites, mines, soil moisture, and vegetation. This is distinct from airborne radiometrics, MT, and H-K5 InSAR.

USGS Landsat Collection 2 surface reflectance · no scenes are cached.

Rank 3 · new time dimension

ComCat earthquake migration / swarm geometry

Model time-ordered, uncertainty-weighted event migration and depth progression; H-K3 only had static seismic-density fields. Potential is moderate-to-high only where the catalog is complete and activity is present; cost high. Mimics include aftershocks, geothermal injection, volcanic swarms, quarry blasts, and network changes.

USGS ComCat · API/docs reviewed; no AOI query was run.

Rank 4 · sparse hydrogeology

Groundwater head discontinuity / seasonal lag

Test persistent head offsets and recharge-response phase shifts across candidate structures using matched monitoring wells and aquifer/pumping controls. Potential is low-to-moderate and coverage-dependent; cost high. Mimics include aquifer contacts, pumping, irrigation, recharge variation, and well construction.

USGS Water Data APIs · no AOI query was run.

  • Official GEMS Prize Reference Solution
    Repository and notebook fetched by GitHub API in this session; notebook parsed locally. The notebook uses alpha=0.2 and beta=0.8 in a Tversky loss. This is loss-weight corroboration only; it does not verify the organizer's scoring implementation, a leaderboard result, or any owner's score claim.
  • INGENIOUS — Great Basin Regional Dataset Compilation
    Official record inspected via search. The local CSV/ZIP copies were restored from an owner-controlled mirror and SHA-256 checked against that mirror; official-host bytes were not directly downloaded in this session. The compilation includes regional well/spring temperature and chemistry material and geothermal-feature datasets. Local mirrored CSV has measured-temperature and quartz/chalcedony/Na-K-Ca columns; column-level provenance should be rechecked against the official data dictionary before new modeling.
  • GeoDAWN airborne magnetic and radiometric surveys of northwestern Great Basin, Nevada and California
    Official USGS data-release record located and reviewed via search. The competition-area raster copies in the workspace are owner-mirror derivatives; this session did not download source grids from USGS. Existence and scope of the official airborne magnetic/radiometric data release.
  • USGS 3D Elevation Program — Products and Services
    Official pages located and reviewed via search. No additional 3DEP tiles were downloaded in this review. Official access pathways and statement that 3DEP products are available free of charge and without use restrictions; does not establish tile coverage for a particular AOI.
  • State Geologic Map Compilation (SGMC) geodatabase of the conterminous United States
    Official publication record located and reviewed via search. The workspace contains an owner-derived fault raster, not the official geodatabase. Official description and citation for the SGMC. Any use as a holdout proxy must retain the stated limitations and avoid using the fault raster as a predictor.
  • USGS ANSS Comprehensive Earthquake Catalog (ComCat) documentation
    Official catalog documentation located and reviewed via search. No event query or event file was downloaded in this review. Catalog fields include event time, hypocenter depth, magnitude, and location/quality metadata. Catalog completeness and location uncertainty vary by network and event.
  • Landsat Collection 2 Level-2 Surface Reflectance
    Official USGS product and access pages located and reviewed via search. No imagery was downloaded in this review. Atmospherically corrected multispectral surface-reflectance products, including SWIR bands; official collection is available through EarthExplorer.
  • USGS Water Data APIs
    Official modern API hub located and reviewed via search. No AOI query was made in this review. Machine-readable access to USGS water data and monitoring-location metadata. Coverage, parameter availability, and measurement quality must be checked before modeling.
