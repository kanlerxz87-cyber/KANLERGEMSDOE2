Why did the reported 0.2778 lead these sites?

Sparse placement can reduce redundant predictions, and removing low-credit known-fault flanks can improve the precision/coverage tradeoff under a distance-weighted metric. This is a plausible explanation, not causal proof: hidden truth and organizer receipts linking those exact bytes to the reported result are unavailable.

The target here is fault prediction; geothermal relevance is a scientific motivation, not the directly validated target.
