Ranked hypotheses before experiments

These are mechanistic ideas, not claims of proven novelty. The repo and registry are currently absent, so uniqueness from prior work cannot be confirmed. No expected numerical score is published.

  1. Cross-scale edge-decoupling at buried basement steps — surface conductivity/depth-to-conductive-base plus gravity anomaly/slope and TMI gradients; multi-scale oriented edge ridges measure persistent separation of shallow and deeper boundaries. Could reveal a buried fault beneath conductive cover. Mimics: lithologic contacts and basin geometry. Medium cost.
  2. Strain-gradient segmentation with independent geophysical corroboration — dilatation, shear strain, strain invariant plus TMI/gravity edges; detect persistent changes in strain-corridor orientation/width and require a second-domain edge. Could find structural continuations absent from surface catalogues. Mimics: regional deformation gradients. Medium/high cost.
  3. Earthquake-density anisotropy residual — official earthquake-density feature only; remove broad regional background then identify directional local lineaments and test orientation against potential-field edges. Could isolate fault-aligned seismicity not represented by broad density. Mimics: uneven event detection and non-fault seismicity. Low/medium cost; confirm band metadata.
  4. Topographic–potential-field contact discordance — detrended elevation/slope and TMI/gravity slopes; require persistent geophysical boundaries where topographic fault evidence is weak, with matched-contact controls. Targets concealed breaks rather than scarp-only evidence. Mimics: erosional edges and mapped lithology. Low/medium cost; likely overlap with prior methods, so check source code before selecting.

How to submit — only after approval

  1. Obtain authorized competition inputs from the DrivenData data tab. Keep private data outside Git; this checkout cannot sign in or fetch them.
  2. Use the canonical shared template's cached stack, whole-segment hide-and-recover evaluator, and writer. Recompute catalogue-based features from visible faults only; exact-mask them.
  3. Run each feature leakage canary, then a spatially blocked HOLDOUT-DTI with evaluator version, withheld positives, and paired 95% CI. Compare only same-evaluator results.
  4. Compare the pre-placement surface and final dots to every registry raster; enforce |Spearman| ≤0.90 and ≤70% within 3 px. Any missing registry means uniqueness is unknown, so stop.
  5. Validate the exact written TIFF against the official sample template: one float32 band, matching CRS/shape/transform, finite values in `[0,1]` on the footprint, null/nodata outside. Use scripts/validate_submission.py; it fails closed and does not grant scientific approval.
  6. Only a separate selector may approve a weekly slot. Then on DrivenData, choose New submission, upload the exact approved `.tif` (or zip containing one TIFF), add a unique name and a ≤140-character note, check weekly quota, and submit. Save the receipt and hash as ORGANIZER-CONFIRMED evidence.
