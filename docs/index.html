04 / SCIENCE, NOT A PROJECTION

The important
distinction.

An attractive map is not evidence that a candidate will generalize to unseen faults.

01

Respect the metric

Distance-weighted Tversky rewards spatially tolerant fault recovery. A 300 m triangular kernel and α = 0.2, β = 0.8 govern the trade-off; prediction-side and truth-side proximity credits are not interchangeable.

02

Hold out entire fault segments

Future estimates require buffered segments, features built from visible faults only, pixel-exact masking, pooled DTI and a spatial-block confidence interval—not a projected leaderboard score.

03

Expose the caveats

The stopped implementation used unsigned magnitudes, not the proposed signed polarity, and its full-catalogue-masked surface canary was invalid for held-out folds. A shared evaluator pooling defect was reported upstream; no DTI was calculated here.

04

Validate the saved bytes

A future TIFF must match the grid and be finite and within [0,1] inside the footprint. The written specification says null/NaN outside; the reported portal error makes exterior encoding unresolved without organizer confirmation.

05 / THE PATH FORWARD

What comes next.
