# Pre-implementation hypothesis slate — 28 October 2026

**Research proposals, not experiments or submission recommendations.** The request refers to a separate method paragraph, but does not contain one. The previously frozen, explicit lane is [HTCADS-K2](../registry/preregistration_htcads.json). These ideas are proposed as possible **ablations within that lane**, not permission to alter it. Before any new method is fitted or emitted, resolve the literal uniqueness stop. No leaderboard-score improvement is estimated here.

The rank below is a qualitative judgment about possible incremental discovery at reasonable cost, not a DTI prediction. We inspected local `src/gems/`, `src/gems32/`, the prior hypothesis slates and the nine focus-site records; the broader fleet has not been searched exhaustively. Existing mechanisms overlap these proposals, so uniqueness or an entirely untried method is **not established**. Every catalogue-derived input must be reconstructed from visible segments inside each fold. Do not use external fault traces as held-out truth or features without a documented contamination analysis.

## Controls and intended validation, only if the stop is resolved

1. Freeze one hypothesis, inputs, preprocessing, spatial splits, budget and acceptance rule before fitting. Do not change the budget just to exploit the calibration-lattice gaps.
2. Compare the pre-placement surface with **every** current registered raster; stop for rank-correlation above 0.90. Withhold complete connected fault components with a spatial buffer; reconstruct every catalogue feature from only fold-visible faults. Mask visible fault pixels exactly.
3. Test every raw and derived feature separately for leakage; AUC above 0.90 is a stop pending proof otherwise. Fit and evaluate the same-evaluator current best on the same folds. Pool the 300 m triangular-kernel distance-weighted Tversky components (alpha 0.2, beta 0.8), and publish withheld-positive occurrences, spatial paired 95% CI and canary receipts.
4. Compare the final dots against the complete current registry using the literal directional 3-pixel rule as well as rank correlation. Verify saved TIFF bytes with the shared writer and validator. A new hash, a passing local format check or a hypothetical holdout win alone cannot authorize upload. A separate account-aware selector is required.

## Official grounding and scope

The [competition problem and metric](https://www.drivendata.org/competitions/306/competition-doe-gems/page/967/) target fault prediction, not direct proof of a geothermal vent. A [USGS account of Great Basin blind geothermal exploration](https://www.usgs.gov/publications/discovering-blind-geothermal-systems-great-basin-region-integrated-geologic-and) describes structural, gravity, magnetic and thermal evidence and also gives a documented blind system with no surface springs, fumaroles or paleo-geothermal deposits. That case supports investigating multiple evidence channels; it does not validate any proposed feature or imply a leaderboard result.
